# Lost and Found Management System

## About
A database-based Lost and Found Management System designed to manage and track lost and found items efficiently.

## Technologies Used
- MySQL
- SQL
- MySQL Workbench

## Features
- Register lost and found items
- Search and manage item records
- Store user and item information
- Relational database using Primary Key and Foreign Key

## Project Purpose
This project was developed to provide an organized way to manage lost and found items within a college campus.
